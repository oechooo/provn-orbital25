# Render Deployment Guide

## Overview

This project is configured for deployment on Render with SQLite database. The deployment includes:
- Backend: Node.js API with Prisma ORM and SQLite
- Frontend: React SPA built with Vite

## Pre-deployment Checklist

1. **Get a News API Key**
   - Visit https://newsapi.org/
   - Sign up for a free account
   - Get your API key

2. **Update Environment Variables**
   - Set `NEWS_API_KEY` in Render dashboard
   - JWT_SECRET will be auto-generated by Render

## Deployment Steps

### Option 1: Using render.yaml (Recommended)

1. **Push to GitHub**
   ```bash
   git add .
   git commit -m "Deploy to Render"
   git push origin main
   ```

2. **Connect to Render**
   - Go to https://render.com
   - Create new account or sign in
   - Click "New +" → "Blueprint"
   - Connect your GitHub repository
   - Select this repository
   - Render will automatically detect the `render.yaml` file

3. **Set Environment Variables**
   - In the Render dashboard, find your backend service
   - Go to Environment tab
   - Add: `NEWS_API_KEY=your_actual_api_key_here`

### Option 2: Manual Service Creation

#### Backend Service
1. Create new "Web Service"
2. Connect your GitHub repo
3. Configure:
   - **Build Command**: `cd backend && npm install && npx prisma generate && npm run build`
   - **Start Command**: `cd backend && npm run startup && npm start`
   - **Environment Variables**:
     - `NODE_ENV=production`
     - `DATABASE_URL=file:./dev.db`
     - `JWT_SECRET=<generate-random-string>`
     - `NEWS_API_KEY=<your-api-key>`
     - `PORT=10000`

#### Frontend Service
1. Create new "Static Site"
2. Connect same GitHub repo
3. Configure:
   - **Build Command**: `cd frontend && npm install && npm run build`
   - **Publish Directory**: `frontend/dist`
   - **Environment Variables**:
     - `VITE_API_URL=https://your-backend-url.onrender.com/api`

## Post-Deployment

1. **Verify Services**
   - Backend health check: `https://your-backend-url.onrender.com/health`
     - Should return status "OK" with database connection info
   - Frontend: `https://your-frontend-url.onrender.com`

2. **Database Initialization**
   The SQLite database is automatically initialized on deployment with:
   - Database schema creation
   - Initial setup verification
   - Health check validation

3. **Populate Database**
   You can populate the database by:
   - Using the admin user creation script
   - Running news fetching scripts
   - Manual data entry through the frontend

## Important Notes

- **JWT Tokens**: Configured to never expire for simplified deployment
- **SQLite Persistence**: Database will reset on each deployment
- **Cold Starts**: Free tier services may take 30+ seconds to wake up
- **Environment Variables**: Make sure to set your actual News API key
- **CORS**: Frontend URL is automatically configured in backend CORS settings

## Troubleshooting

### Common Issues

1. **Build Failures**
   - Check that all dependencies are listed in package.json
   - Verify TypeScript compilation with `npm run build` locally

2. **Database Issues**
   - SQLite file is created automatically
   - Check logs for Prisma connection errors

3. **API Connection Issues**
   - Verify VITE_API_URL in frontend environment
   - Check CORS configuration in backend

### Logs

- Backend logs: Available in Render dashboard → Service → Logs
- Build logs: Available during deployment process

## Local Development

After deployment, you can still develop locally:

```bash
# Backend
cd backend
npm run dev

# Frontend (new terminal)
cd frontend
npm run dev
```

Local development will use your `.env` file with localhost URLs.
